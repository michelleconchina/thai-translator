## Risks
- `@concurrent` needs the Swift 6.2 toolchain (Xcode 26.2 is installed) and is the way to leave the caller's actor under `SWIFT_APPROACHABLE_CONCURRENCY`; if it doesn't compile in Swift 5 language mode, fall back to `Task.detached` inside `loadInBackground()` and note it under Decisions.
- `PhraseCategory` must be `Hashable` for `navigationDestination(for:)`; it is (raw-value enum), but it's `nonisolated`, so the destination closure stays on the main actor; no change expected.
- Navigation and search can't be verified by `xcodebuild` without UI tests (removed for now), so the tap/search checks in Phases 2–3 are manual and listed as such.
- Thai search: Thai has no spaces between words and `localizedStandardContains` works on substrings, so searching "เผ็ด" matches; tone marks are part of the text and must be typed.
## Decisions
- `@Observable` store owned by the root view via `@State`, no new libraries; matches the ios-swift skill (Observation on iOS 17+).
- Store loads through an injected `@Sendable` closure so tests use fakes (success, failure) and never touch disk; the real seed stays covered by `PhraseSeedTests`.
- Each category gets an SF Symbol (e.g. greetings `hand.wave`, prices `tag`, directions `signpost.right`, taxi `car`, food `fork.knife`, emergency `cross.case`); it lives on `PhraseCategory` as `systemImage`.
- Phase 2 rows show the base Thai/romanized text without a particle; Phase 3 adds the particle once the default is chosen.
- Default polite particle: ค่ะ (`kha`), chosen by you on 2026-10-24; stored as the `@AppStorage("politeParticle")` default and switchable in the toolbar.
- Out of scope: favorites (SwiftData), the full-screen show card, keeping the screen awake, a first-launch particle prompt, deployment target change.
